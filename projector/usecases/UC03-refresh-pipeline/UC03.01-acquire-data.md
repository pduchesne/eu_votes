# UC03.01 — Acquire and Normalize Data

A maintainer fetches raw EP vote and MEP data from the documented source and normalizes
it into the queryable store, for a given term, via documented commands — with
provenance recorded along the way. Completing this means the data is "extracted and
ready to process", independent of whether any mining has run yet.
